Colored boxes are what the frozen detector actually produced; a structure counts as recovered when a box of its class overlaps the annotation by at least half. Each example is drawn at one fixed display zoom, so what changes on screen is exactly the inferred factor, and the canvas plays the part of the detector's fixed anchors: the anatomy starts too small or too large for them and ends at the size they were trained on.

Why one number per image is enough

Vendor, depth and zoom decide how many pixels a structure occupies. A detector carries the size distribution of its training site in its anchor assignment and in the pyramid level on which each object is resolved, so when the anatomy arrives larger or smaller it is resolved at levels the detector was never trained for, even though every structure is present and plainly visible.

TAC treats that apparent scale as one latent variable per image. Each first-pass box votes for the displacement that would return it to the canonical size of the structure it claims to be, and each vote is weighted by how plausible that size is and by how much the detector believes the box, so boxes that land on nothing lose influence instead of having to be thresholded away. Three closed-form updates give the factor, and the curvature of the same objective gives a spread that decides how far apart the extra views sit and whether they are acquired at all.
